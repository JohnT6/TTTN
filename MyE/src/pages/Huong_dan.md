Trong thư mục "pages" này sẽ chứa toàn bộ (Html, CSS, Js)
* Lưu ý: CSS này dùng thuần + Tailwind css
=> Yêu cầu làm Html, Css(Bootstrap) + Css thuần(nếu Bootstrap không hỗ trợ hiệu ứng đó), JS. 
* Đối với file Css, Js thì bỏ vào thư mục "assets" theo từng forder riêng.
Quy chuẩn đặt tên file Css/Js (Tên file giống tên file Html chỉ khác đuôi file). ví dụ: Nap_game.html -> Nap_game.css -> Nap_game.js
